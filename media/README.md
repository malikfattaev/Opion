# Media

Единое хранилище всех материалов бренда Opion: логотипы, съёмки, посты, видео.

## Структура

```
media/
├── brand/                  Фирменный стиль
│   ├── logo/
│   │   ├── primary/        Основной логотип (svg + png, светлая/тёмная версии)
│   │   ├── wordmark/       Текстовое начертание без знака
│   │   ├── icon/           Знак без текста (аватарки, favicon-источник)
│   │   └── favicon/        Готовые иконки сайта и мини-аппа
│   ├── palette/            Свотчи, .ase / .clr, референсы цветов
│   ├── typography/         Шрифтовые файлы и лицензии
│   └── guidelines/         Брендбук, правила использования
│
├── products/               Товарная съёмка
│   ├── raw/                Исходники с камеры (в git не попадают)
│   ├── retouched/          После обработки, мастер-файлы
│   ├── catalog/            Готовые карточки для сайта и мини-аппа
│   └── lookbook/           Имиджевые кадры, образы
│
├── social/                 Контент для соцсетей
│   ├── posts/              Лента (1:1, 4:5)
│   ├── stories/            Сторис (9:16)
│   ├── reels/              Обложки и статика для reels
│   ├── covers/             Шапки, аватары каналов
│   └── templates/          Шаблоны под повторяющиеся рубрики
│
├── video/                  Видео
│   ├── raw/                Исходный материал (в git не попадает)
│   ├── edited/             Проекты монтажа
│   └── exports/            Финальные экспорты
│
├── site/                   Графика под веб
│   ├── hero/               Первые экраны
│   ├── banners/            Промо-баннеры, акции
│   ├── og/                 Open Graph / превью для мессенджеров
│   └── icons/              Иконки интерфейса
│
└── press/                  Пресс-кит, материалы для партнёров
```

## Правила

1. **Именование:** `kebab-case`, без пробелов и кириллицы.
   Формат: `<что>-<деталь>-<вариант>.<ext>`, например `logo-primary-dark.svg`,
   `hoodie-black-front-01.jpg`, `post-2026-03-sale-1x1.png`.
2. **Даты** в названии всегда `YYYY-MM-DD`, чтобы файлы сортировались хронологически.
3. **Векторы важнее растра.** Логотипы храним в `.svg`, растр только как экспорт.
4. **Git не хранит тяжёлые исходники.** Расширения `.psd`, `.ai`, `.mp4`, `.mov`,
   RAW-форматы и архивы исключены в корневом `.gitignore`. Они лежат локально и в
   облаке команды; в репозитории остаётся структура папок и лёгкие финальные ассеты.
5. **Ассеты, которые реально отдаются пользователю, копируются в код:**
   сайт в `web/public/`, мини-апп в `app/public/`. `media/` остаётся источником правды,
   а `public/` оптимизированной витриной (webp/avif, сжатый svg).
